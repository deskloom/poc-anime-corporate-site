# ほしあかり精機 公式サイト風デモ（自主制作）

架空の産業部品メーカー「株式会社ほしあかり精機」の公式サイトを想定した、**自主制作のデモサイト**です。
会社・製品・データ・キャラクター「ともり」はすべて架空で、このために自作したものです。実在の企業や、実際の制作案件とは関係ありません。
画像・フォント・音声・動画の外部素材は使っていません（図形はインラインSVG／CSS／canvasで描画、音はWeb Audioで合成）。フレームワーク・CDNも不使用で、素のHTML/CSS/JSだけで動きます。

## このデモで見せたいこと

「アニメ映画の特設サイトのような世界観」と「BtoBサイトとしての使いやすさ」を両立できるか、という試みです。想定する訪問者は2種類います。

- **世界観を楽しむ人** … トップページの全画面ビジュアル、案内役「ともり」のセリフ、スクロールで切り替わる4つのシーン。
- **製品へ直行したい人** … ヘッダーにつねに表示される「製品を探す」ボタン、キーボード用スキップリンク、各シーン末尾の素直なカテゴリリンク、装飾の少ない検索ページ。

## ページ一覧（`docs/`）

| ページ | 内容 |
|---|---|
| `index.html` | トップ。ローディング（最長約1秒・スキップ可・同一セッションの再訪では非表示）、キービジュアル3シーン（01/02/03ボタン＋自動切替、ホバー/フォーカス/停止ボタンで一時停止）、スクロールストーリー4シーン、事業概要、技術、お知らせ、資料、CTA |
| `products.html` | 製品検索。用途・困りごと・寸法(W/H/D)・性能・使用温度・品番(前方一致)で即時絞り込み、並び替え、比較(最大3件)、★お気に入り、閲覧履歴(直近10件)、比較表、品番を引き継いだお問い合わせ |
| `product.html?id=品番` | 製品詳細。仕様表、関連製品、図面(SVG)・仕様書(CSV)のダウンロード、印刷・PDF保存（A4用の印刷スタイル） |
| `contact.html` | お問い合わせフォーム。品番は`?parts=`または比較中の製品から事前入力され、チップで追加・削除できます。クライアント側で入力チェックし、確認画面を出すだけです（送信はしません） |
| `admin.html` | 「社内更新デモ」。製品・お知らせの追加/編集/削除、初期状態に戻す、JSONエクスポート/インポート。ログインはありません |

## 仕組み

- **スクロールシーン** … `IntersectionObserver`で画面中央にあるシーンを判定し、背景・ともりのポーズと表情・セリフをCSSのトランジションで切り替えます（切り替わり時に光がふわっと走ります）。各シーンには関連カテゴリへの通常リンクがあります。
- **サウンド（初期オフ）** … ヘッダーの「♪」ボタンで切り替え。Web Audio APIで穏やかなパッド音を合成します（音声ファイルなし）。選択は`localStorage`に保存されます。ブラウザの仕様上、再訪時にオンだった場合も最初の操作（クリック/キー）で再生が始まります。
- **動きを減らす設定** … OSの`prefers-reduced-motion: reduce`では、自動切替・パララックス・粒子のアニメーション・シーン切り替え演出を止めます（内容はすべてそのまま表示されます）。
- **検索・比較・お気に入り・履歴** … 検索ロジックは`docs/js/search.js`の純粋関数（ブラウザ/Node両対応）。比較・お気に入り・履歴は`localStorage`に保存されます。
- **印刷・PDF保存** … 製品詳細の「印刷・PDF保存」で`window.print()`を呼びます。印刷用CSSがヘッダーやボタン類を隠し、A4の仕様書として出力します。PDF保存はブラウザの印刷ダイアログから行います。
- **社内更新デモ** … 編集内容は`localStorage`に保存され、同梱の`data/*.json`より優先して表示されます。サーバーには何も送りません。「初期状態に戻す」で破棄できます。

## ローカルで動かす

`fetch`でJSONを読むため、`file://`ではなく静的サーバー経由で開いてください。

```
npx serve docs
```

（Python等、任意の静的サーバーでも可。すべて相対パスなので、GitHub Pagesのサブパス配下でも動きます。）

## テスト

検索・並び替え・比較(最大3件)・履歴(重複除去/10件)などの純粋関数を`node:test`で確認します。依存パッケージはありません。

```
npm test
```

（`node --test`と同じ。Node 22では`node --test tests/`のディレクトリ指定が使えないため、引数なしで自動検出させています。）

製品データを作り直す場合は`npm run gen-data`（`scripts/gen-data.js`）。

## 既知の制限

- お問い合わせは送信されません（デモ）。管理画面に認証はありません。
- データはすべて架空で、仕様値は実在の規格・製品に基づきません。
- 図面は平面図・正面図に寸法を入れた簡易なSVGで、実際の設計図面ではありません。
